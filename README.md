# gude.co

Static site for [gude.co](https://gude.co) — parent hub with three service lanes:

- Plan Review → `plans.gude.co`
- Engineering → `dixon.gude.co`
- Evaluation → `evaluation.gude.co`

Hosted on GitHub Pages from this repo (`main`, `/`). GoDaddy holds the domain `gude.co` (account 617092701) and DNS only.

| Path | URL |
|------|-----|
| `index.html` | `gude.co` |
| `plans/index.html` | `plans.gude.co` (subdomain → `plans/` folder) |
| `plans/docs/*.pdf` | Plan review intake checklists (bundled for download) |
| `dixon/index.html` | `dixon.gude.co` |
| `brand/` | Color source of truth (`theme.css` + `palettes.html`) — see `brand/README.md` |
