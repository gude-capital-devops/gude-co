VERIFY

Engineering stamp records

Scan the QR code beside a Gude engineering stamp to open the matching verification record for that document set. Each record shows the document identifier, responsible engineer, and whether the set is a prototype, in review, or authorized for use.

How it works

The QR code encodes a unique URL on gude.co. If the URL opens a verification page, the stamp matches a published record. If no page is found, treat the stamp as unverified and contact the engineer listed on the drawing set or office@gude.co.
