gude.co color schemes

v3 palette sheet. This file lives next to the site at gude.co/brand/palettes.html. Live tokens are in theme.css — currently Red Field on the landing pages (Crimson Field ground, white type, white buttons). Signal Red (#C23034) is a true mid red — not orange, not burgundy. Do not put Signal Red on Crimson Field. SVG fills so color survives print-to-PDF.
